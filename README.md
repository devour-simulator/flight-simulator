# 737-800 3D 飞行模拟器

公开地址：<https://devour-simulator.github.io/flight-simulator/>

这是一个基于 Three.js、直接在浏览器运行的民航飞行模拟器。当前主力机型为 Boeing 737-800，并包含一架驾驶手感、性能和运营成本不同的 Q400。

## 当前功能

- 737 驾驶舱：PFD、ND、EICAS、MCP、EFIS、CDU/FMC、顶板、中央操纵台、配平、方向舵脚蹬、起落架、襟翼和减速板。
- 飞机系统：电瓶、地面电源、APU、双发启动、AC BUS 1/2、备用直流、发动机发电机、液压、三油箱供油、IRS、偏航阻尼、引气、增压、防冰和火警联动。
- FMC：起点/终点、SID、STAR、ILS/RNAV/目视进近、航点、巡航高度、重量、重心、V1/VR/V2，以及 LEGS 页速度/高度限制和 LNAV/VNAV 航路。
- 飞行模型：迎角失速、重量、空气密度、温度、推力衰减、升阻力、起落架阻力/超速损伤、天气、阵风和操纵液压。
- 完整航班：冷舱、地勤、推出、滑行、起飞、爬升、巡航、进近、自动降落、滑跑、关车与实时 SOP 清单。
- 飞行环境：多机场、NPC 飞机、鸟群、山体、建筑、天气、昼夜、跑道灯和机场车辆。
- 长期玩法：航空公司经营、飞机购买/维护、世界航线、职业任务、考试、ATC、乘客舒适度、完整航班评分、排行榜、回放和拍照模式。
- 输入输出：键盘鼠标、Gamepad/摇杆轴、死区/灵敏度/反向校准、全屏和可弹出的第二屏仪表窗口。
- 声音：发动机、APU、启动机、起落架/襟翼动作、爆炸、警告与 GPWS 高度/危险语音。

## 操纵

- 地面：`Q` 左转，`E` 右转；低速时锁定 `W/S/A/D`。
- 起飞：推力到 TO/GA，达到抬轮速度后按 `W`。
- 空中：`W/S` 俯仰，`A/D` 滚转，`G` 起落架，`F` 增加襟翼档位，`V` 切换视角。
- 鼠标拖动调整视野，外部视角滚轮调整距离，双击复位视角。

## 本地运行与验证

```text
npm run build
node scripts/verify-autoland.mjs
node scripts/verify-runtime-autoland.mjs
```

构建输出位于 `dist/static`。GitHub Pages 从 `codex/flight-simulator` 分支发布。

## 版本

当前大版本：Software L3 Systems 2。

“Software L3”表示浏览器内的软件固定式驾驶舱架构；它不是经过认证的飞行训练设备，也不包含真实物理座舱、力反馈或运动平台。
